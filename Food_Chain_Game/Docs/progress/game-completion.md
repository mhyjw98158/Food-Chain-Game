# 게임 완성에 필요한 기능·디테일 (2026-10-30 작성)

Among Us / Goose Goose Duck 같은 소셜 추리 게임 수준으로 "끝까지 플레이할 수 있는 게임"이 되려면 무엇이 더 필요한지 정리한 목록이다.
진행 상태는 여기 쓰지 않는다(`progress.md`). 여기서 할 일로 정한 항목은 `plan.md`의 맞는 단계로 옮겨서 진행한다.

- 표시: **[필수]** 출시에 꼭 필요 / **[중요]** 완성도에 크게 영향 / **[다듬기]** 있으면 좋음 / ★ 사용자 결정 필요
- 이미 `plan.md`에 있는 항목은 "→ plan" 으로만 적고 자세히 다시 쓰지 않는다

## 0. 지금 있는 것 (기준선)

역할 배정(인원별 후보), 낮·밤 4일 라운드, 포식자 공격(라운드당 1회)·굶주림, 동물별 승리 조건, 미션 17종(미니게임), 탐색·부검, 위장(카멜레온)·예측(올빼미), 공생 시야 공유(얼룩말·타조), 시야(2D 빛 + 마스크), 미니맵, 근접 음성(생존자/유령 분리), 채팅·귓속말·메모, 로비 커스터마이징, 설정(키·음량·음성), 방 코드 입장(Node 서버), 결과 화면 → 로비 복귀.

**코드로 확인한 빈 곳:** 토론·투표(회의) 시스템 없음, 효과음은 낚시 미션 4개와 UI 3개뿐, 튜토리얼·공개 방 목록·재접속·현지화 없음.

## 1. 핵심 규칙 — 먼저 정해야 나머지가 정해진다 ★

이 장르의 재미는 "정보를 모아 → 말로 설득하고 → 함께 결정하는" 데서 나온다. 지금은 탐색·부검으로 정보를 얻어도 **그 정보를 쓸 곳(공개 토론·집단 결정)이 없다.** 피식자가 포식자에게 대응하는 수단도 전갈 반격뿐이다.

- [ ] **[필수] ★ 회의(토론·투표) 시스템을 넣을지, 넣는다면 어떤 모양인지**
  - 예: 시체를 발견해 알리면 모두 한 곳(물웅덩이 등)으로 모여 토론 → 투표로 한 명을 내쫓음 / 낮이 시작될 때마다 짧은 회의 / 긴급 소집(1인 1회)
  - 넣으면 필요한 것: 시체 신고 버튼, 회의 화면(참가자 목록·생존 표시·발언 중 표시), 토론·투표 시간, 투표 결과·동점 처리, 추방 연출, 추방된 사람 역할 공개 여부 ★, 회의 중 이동·미션 정지, 회의 중 음성은 거리 상관없이 전원
  - 넣지 않으면: 피식자가 정보를 쓰는 다른 방법이 필요(예: 탐색 결과로 포식자 접근 경고, 피식자끼리 힘을 합쳐 포식자 퇴치)
- [ ] **[필수] ★ 피식자 팀 승리 조건을 "버티기" 말고도 둘지** — 예: 전체 미션 진행도가 다 차면 승리(공용 진행 바). 지금은 피식자가 할 수 있는 게 미션·도망뿐이라 긴장감이 한쪽으로 쏠린다
- [ ] **[필수] 시간·횟수 밸런스** — 낮·밤 각 20초(테스트용으로 보임), 4일, 공격 라운드당 1회, 시야 6/8/11, 미션 최소 시간. 실제 7~10인 테스트로 정하고 방장이 바꿀 수 있게(3장 게임 설정)
- [ ] **[중요] ★ 공격 규칙 세부** — 공격 쿨타임을 둘지(지금은 라운드당 1회만), 낮에도 공격할 수 있는지, 공격 직후 공격자에게 보이는 흔적(피 묻음 등)을 남길지
- [ ] **[중요] ★ 포식자 쪽 방해 수단(사보타주에 해당)** — 피식자를 한곳에 모으거나 흩어놓는 장치. 예: 물웅덩이 오염(일정 시간 안에 여럿이 고쳐야 함), 밤을 앞당김, 특정 구역 시야 축소
- [ ] **[중요] ★ 빠른 이동 수단** — 구역 사이 지름길(굴, 강물 타기 등)을 일부 동물만 쓰게 할지. 포식자의 도주 수단이 되어 추리 요소가 생긴다
- [ ] **[중요] ★ 같은 편끼리 서로 아는지** — 포식자끼리, 까마귀↔늑대, 얼룩말↔타조(지금은 공생으로 연결)를 서로에게 보여 줄지
- [ ] **[중요] 인원별 역할 구성표** — 지금 `RoomManager.GetCharacterPool`은 고정 순서 목록의 앞에서부터 인원수만큼 자른다(9명 이하: 까마귀·늑대·전갈·타조·얼룩말·하마·올빼미·미어캣·악어·카멜레온 순, 10명 이상: 매·하이에나·물떼새 추가). 그래서 같은 인원이면 매번 같은 역할 세트가 나오고(누가 받는지만 무작위), 3명이면 까마귀·늑대·전갈뿐이다. 인원별로 포식자 수·중립 역할 수를 정한 구성표와 그 안에서의 무작위 선택이 필요. 방장이 구성을 고를 수 있게 할지 ★
- [ ] 미완성 캐릭터 능력·미션 → plan 2·3단계(하마 복수, 새 동물 능력)

## 2. 플레이 중 경험(UX)

- [ ] **[중요] 결과 화면 추가 정보** — 사망 순서·원인, 간단한 통계(미션 수, 탐색 수)
- [ ] **[필수] 사망·추방 연출** — 사망 연출은 자리만 있음(`GamePlayUI.deathEffectUI`, handoff 참고). 공격 당하는 순간의 짧은 연출(포식자별로 다르게)
- [ ] **[필수] 처음 하는 사람을 위한 안내** — 역할 소개 화면에 "할 수 있는 것·키"까지, 게임 중 언제든 다시 볼 수 있는 역할 설명(지금 캐릭터 소개 5초만), 규칙 설명서(타이틀/로비)
- [ ] **[중요] 미션 안내** — 남은 미션 목록에 위치 표시(미니맵 마커는 있음), 화면 가장자리 방향 화살표, 미션 완료 효과음·연출
- [ ] **[중요] 상황 알림** — 낮/밤 전환 경고(10초 전), 마지막 날 알림, 굶주림 경고(포식자 본인에게), 공생 파트너 사망 알림
- [ ] **[중요] ★ 유령이 할 수 있는 것** — 지금은 돌아다니며 대화만. 남은 미션을 대신 해서 팀을 돕기, 다른 플레이어 시점 따라 보기(관전)
- [ ] **[다듬기] 감정 표현(이모트), 빠른 채팅 문구**
- [ ] **[다듬기] 게임 중 플레이어 목록에 음성 발언 표시·개별 음량** (로비에는 있음)

## 3. 로비·방

- [ ] **[필수] 방장 게임 설정 화면** — 라운드 수·낮밤 시간·시야·공격 규칙·미션 수·역할 구성을 방장이 바꾸고, 전원 화면에 보이게(서버가 값 검증). 수치는 이미 대부분 `[SerializeField]`라 런타임 값으로 옮기면 된다
- [ ] **[필수] 시작 조건** — 최소 인원 검사(→ plan 6단계 방 정원), 준비 표시, 시작 카운트다운(그동안 취소 가능)
- [ ] **[필수] 방장 권한** — 강퇴(같은 게임 재입장 차단), 방장 넘기기
- [ ] **[중요] ★ 공개 방 목록·빠른 참가** — 지금은 방 코드로만 들어온다. 친구끼리만 할지, 모르는 사람과도 하게 할지에 따라 필요
- [ ] **[다듬기] 로비에서 할 것** — 연습용 미션 오브젝트, 커스터마이징 미리보기, 지난 판 결과 다시 보기

## 5. 아트·사운드

- [ ] **[필수] 맵 아트** — 지금은 색칠한 사각형. 구역(숲·들판·강·하늘)별 타일·소품, 벽·장애물이 시야 그림자와 맞게
- [ ] **[필수] 캐릭터 아트** — 동물별 모습(역할을 숨겨야 하므로 ★ 겉모습은 모두 같은 종으로 둘지, 의상으로만 구분할지 결정), 걷기·대기·공격·사망 애니메이션, 시체 그림. 의상 그림 → plan 3단계
- [ ] **[필수] 효과음** — 발걸음, 공격, 사망, 시체 발견, 미션 시작·성공·실패, 낮밤 전환, 게임 시작·종료, 버튼. `AudioManager`에 넣는 구조는 있음(`EffectSfx`, `UISfx` 목록 확장)
- [ ] **[중요] 배경음** — 로비/낮/밤/긴장(포식자가 가까울 때 등)/결과
- [ ] **[중요] UI 디자인 통일** — 폰트·버튼·창 스타일, 역할·미션 아이콘, 임시 그림 교체(→ plan 3단계)
- [ ] **[다듬기] 화면 효과** — 밤 전환 연출, 피격 흔들림, 미션 완료 파티클
